    Class FileHound<T>

    A fluent query for searching the file system.

    Remarks

    Configure a query by chaining methods, then run it with FileHound.find or FileHound.findSync. Once a search has started the query is locked and can no longer be modified.

    Example

    import { FileHound, ext } from 'filehound';

    const files = await FileHound.create()
      .paths('/tmp')
      .match(ext('json'))
      .depth(1)
      .find();

    Type Parameters

    • T = string

      the type of each match: a path, or a FileWithStats when FileHound.includeFileStats is set

    iterate

    • iterate(options?: SearchOptions): AsyncGenerator<T>

      Asynchronously executes a file search, returning matches one at a time as they are found, in the same order as FileHound.find. Once called, the query is locked and can no longer be modified.

      Parameters

      • options: SearchOptions = {}

        a signal to stop the search

      Returns AsyncGenerator<T>

      an async iterator of matches

      Remarks

      The search runs ahead of the loop by a bounded amount, so a large search can be read without holding every match in memory. Breaking out of the loop stops the search.

      Emits a match event as each match is returned, an error event if the search fails or is aborted and an end event when the search finishes: when every match has been returned, the search fails or is aborted, or the loop is left early.

      Example

      import { FileHound, ext } from 'filehound';

      const query = FileHound.create()
        .paths('/tmp')
        .match(ext('json'));

      for await (const file of query.iterate()) {
        console.log(file);
      }
