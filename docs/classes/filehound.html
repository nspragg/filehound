    Class FileHound

    A fluent query for searching the file system.

    Remarks

    Configure a query by chaining methods, then run it with FileHound.find or FileHound.findSync. Once a search has started the query is locked and can no longer be modified.

    Example

    import { FileHound, ext } from 'filehound';

    const files = await FileHound.create()
      .paths('/tmp')
      .match(ext('json'))
      .depth(1)
      .find();

    find

    • find(): Promise<string[]>

      Asynchronously executes a file search. Once called, the query is locked and can no longer be modified.

      Returns Promise<string[]>

      a Promise of all matches. If the Promise fulfils, the fulfilment value is an array of all matching files

      Remarks

      Emits a match event for each matching file, an error event if the search fails and an end event when the search completes.

      Example

      import { FileHound } from 'filehound';

      const filehound = FileHound.create();
      const files = await filehound.find();

      console.log(files);
